# Optional Kanban pattern

Apply only when the requested product uses this maturity model; it is not a universal workflow or evidence of a released feature.

### Kanban / KI-Landkarte pattern

When the feature is the KI-Landkarte, keep the four maturity levels visible and explicit:

1. Kartografiert — Prozess verstehen.
2. Mit Prompt — KI unterstützt.
3. Mit Agent — Aufgaben delegieren.
4. Automatisiert — Läuft selbstständig.

Each card names the process, gives a one-sentence description, shows its owner, and exposes the next meaningful action. Stage changes are deliberate: forward movement needs an evidence/prompt or agent entry; a drag gesture must not silently mutate the data. A conscious human decision remains a first-class state. Reordering and grouping must have a keyboard-equivalent path.
