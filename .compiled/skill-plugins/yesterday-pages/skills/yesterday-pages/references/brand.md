# Yesterday Brand System

## Character

Yesterday combines a calm editorial foundation with selective brand energy.

- Foundation: warm paper, dark navy, generous space, fine rules, precise hierarchy.
- Energy: orange, purple, green, and yellow mark meaning, progress, or focus.
- Voice: direct, substantial, optimistic, never inflated.

## Color Roles

| Role | Base | Supporting tints |
|---|---|---|
| Paper / ink | `#FBFAF8` / `#181B30` | Body `#2A2D42`, muted `#71758A`, rule `#E3E1DB` |
| Orange: action, friction, human energy | `#FC4E14` | `#F08B61`, `#F5BBA4`, `#F9DDD1` |
| Purple: guidance, AI, active state | `#8977FF` | `#9D9BFF`, `#C7C6FF`, `#E3E3FF` |
| Green: proof, completion, positive outcome | `#17B169` | `#88CCA7`, `#C1E5D3`, `#E0F3E9` |
| Yellow: attention, insight, highlight | `#FFBB38` | `#FED27F`, `#FFECB9`, `#FFF7DF` |

Use one leading accent per page. Add another only when it encodes a separate category. Do not create rainbow decoration.

## Type

- `Source Serif 4`: editorial display, body copy, quotations, reflective moments.
- `Plus Jakarta Sans`: headings, navigation, controls, metadata, labels, charts.
- Editorial pages may be serif-led. Prototypes are sans-led.
- Keep body measures near 60–70 characters. Use compact, balanced headlines.

## Layout

- Reading column: about `880px`; visual breakouts: up to about `1080px`.
- Use a thin masthead with the official wordmark and a literal format label.
- Start with the page thesis. Follow with evidence, implication, then action.
- Number only genuine sequences. Use double rules for a verdict or core principle.
- Prefer spacing and contrast over stacked shadows. Use `12–18px` card radii and larger radii for app shells.
- Pills communicate status or metadata. They are not ornaments.

## Image Direction

Choose observed work over generic office symbolism:

- warm directional daylight, natural materials, credible working environments;
- people thinking, explaining, writing, comparing, or collaborating;
- orange, yellow, purple, or green appearing naturally in objects;
- quiet negative space for text or annotation;
- varied crops: environment, human moment, working detail;
- captions that state why the image matters.

Reject redundant, staged, semantically empty, or visually near-identical images. Never infer a person's identity, role, or emotion beyond visible evidence and supplied context.

## Motion and Interaction

Spend motion on one orchestrated idea. Good uses: reading progress, plot drawing, image reveal, scenario change, process transition. Keep hover effects quiet and functional. A reduced-motion page must preserve the same information and state.

## Brand Assets

- `assets/yesterday-wordmark.svg`: official Academy wordmark.
- `assets/foundation.css`: canonical tokens and shared accessibility primitives.

Font files are not bundled. Use locally licensed fonts when available and the CSS system fallbacks otherwise. No remote font request is required.
