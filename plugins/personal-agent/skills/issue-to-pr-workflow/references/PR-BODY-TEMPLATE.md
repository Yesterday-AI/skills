# PR Body Template

Copy and fill in when creating a PR:

```markdown
## Context (Why)
Why is this change being made? Link the issue.

## Changes (What)
- Bullet point each meaningful change
- Be specific: "Added X to Y" not "Updated code"

## Outcome (Impact)
What is the expected impact? What should work differently after merge?

## Testing
- How was this tested?
- What should the reviewer verify?
- Any manual steps needed?

Closes #<ISSUE_NUMBER>
```
